力扣第 3 题：给一个字符串 `s`，找出不含重复字符的最长子串，返回它的长度。`"abcabcbb"` 的答案是 3（`"abc"`），`"pwwkew"` 的答案也是 3（`"wke"`）。

子串要求连续。`"pwke"` 不算，因为它在原串里不连续。

题目里字符由英文字母、数字、符号和空格组成，都在 ASCII 范围内，最多 128 种。三个解法都靠这一点，用一个长度 128 的数组代替哈希表。

## 先拆一行：`seen[(int)s[r]]`

这题第一次让我看花眼的是这一行，`[]` 和 `()` 都套了两层：

```cpp
seen[(int)s[r]] = true;
```

从里往外读。`s = "abc"`、`r = 0` 时实际打印出来的值：

```
s[r]        = 'a'
(int)s[r]   = 97
seen[97]    = 1
```

| 部分 | 符号 | 作用 |
| --- | --- | --- |
| `s[r]` | `[]` | 取字符串第 `r` 个字符，得到 `'a'` |
| `(int)` | `()` | 类型转换，把字符当成整数用，`'a'` 的 ASCII 码是 97 |
| `seen[...]` | `[]` | 用 97 当下标，找到 `seen` 数组的第 97 格 |

整行的意思是：**把字符 `'a'` 对应的格子标记成「见过」**。每个 ASCII 字符占一格，`'a'` 是第 97 格，`'b'` 是第 98 格，数组下标就是字符的编码。

### 两种括号怎么区分

`[]` 是取下标，有两种场合：

```cpp
bool seen[128];   // 声明时：128 是数组长度
seen[97]          // 使用时：97 是第几格
s[r]              // 取字符串第 r 个字符
```

`()` 在这题里有四种用途：

```cpp
int lengthOfLongestSubstring(string s)   // 函数的参数列表
s.size()  /  max(best, r - l)            // 调用函数，没参数也要写空括号
(int)s[r]                                // 类型转换
while (r < n && !seen[(int)s[r]])        // 包住 while / if 的条件
```

看名字后面跟的是什么：跟 `[]` 是取元素，跟 `()` 是调用函数；括号里只有一个类型名，比如 `(int)`，就是类型转换。

## 方案一：暴力枚举 $O(n^2)$

对每个左端点 `l`，让 `r` 往右扩，遇到见过的字符就停。

```cpp
class SolutionBrute {
public:
    int lengthOfLongestSubstring(string s) {
        int n = (int)s.size();
        int best = 0;
        for (int l = 0; l < n; l++) {
            bool seen[128] = {false};      // 每换一个 l 都要清零
            int r = l;
            while (r < n && !seen[(int)s[r]]) {
                seen[(int)s[r]] = true;
                r++;
            }
            best = max(best, r - l);       // r 停在第一个重复字符上
        }
        return best;
    }
};
```

- **`bool seen[128] = {false}`**：只写了第一个元素，剩下 127 个也会自动初始化成 `false`
- **放在 `for` 里面**：每换一个起点，「见过的字符」要重新记
- **长度是 `r - l`**：`r` 停在重复字符上，有效范围是 `[l, r)`，不含 `r`
- **`r < n` 写在 `&&` 前面**：先确认没越界，才去读 `s[r]`

这个方案用来当对拍的标准答案。

## 方案二：滑动窗口 + 计数数组 $O(n)$

暴力解每换一个 `l` 都从头扫，浪费在于：`[l, r)` 已经确认没有重复了，`l` 往右挪一格，这段的大部分仍然没有重复，没必要重新检查。

滑动窗口维护一段 `[l, r]`，保证里面没有重复字符：

- `r` 每次右移一格，把新字符吃进来，`cnt` 加 1
- 如果新字符的计数超过 1，说明窗口里有重复了，让 `l` 右移，把左边的字符吐出去，直到不重复

```cpp
class SolutionWindow {
public:
    int lengthOfLongestSubstring(string s) {
        int cnt[128] = {0};
        int l = 0, best = 0;
        for (int r = 0; r < (int)s.size(); r++) {
            cnt[(int)s[r]]++;
            while (cnt[(int)s[r]] > 1) {     // 刚吃进来的字符重复了
                cnt[(int)s[l]]--;            // 吐掉左端字符
                l++;
            }
            best = max(best, r - l + 1);     // 窗口两端都算
        }
        return best;
    }
};
```

这里是 `r - l + 1`，方案一是 `r - l`。区别在于：这里的 `r` 是窗口里的最后一个字符，两端都算；方案一的 `r` 停在重复字符上，不算。

里面套了一个 `while`，但复杂度仍然是 $O(n)$。`r` 从头走到尾是 $n$ 步，`l` 只往右走、从不回头，整场下来最多也是 $n$ 步。

**为什么用数组不用 `unordered_set`？** 字符只有 128 种，数组下标直接就是 ASCII 码，不用算哈希，比哈希表快，也更省内存。值域小而且固定的时候，数组优先。

## 方案三：记录上次出现的位置，一步跳过去（提交版）

方案二遇到重复时，`l` 一格一格往右挪。如果知道这个字符上次出现在哪，`l` 可以直接跳到它后面。

`last[c]` 记录字符 `c` 最近一次出现的下标，`-1` 表示没出现过：

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int last[128];
        for (int i = 0; i < 128; i++) last[i] = -1;

        int l = 0, best = 0;
        for (int r = 0; r < (int)s.size(); r++) {
            int c = (int)s[r];
            if (last[c] >= l) {         // 这个字符在当前窗口内出现过
                l = last[c] + 1;        // 跳到它后面
            }
            last[c] = r;
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

初值用 `-1` 而不是 `0`，因为 `0` 是合法下标，没法表示「从没出现过」。所以这里不能写 `int last[128] = {0};`，要用循环一个个设成 `-1`。

`"pwwkew"` 的实际运行过程：

```
r=0 'p' l=0 窗口"p"   best=1
r=1 'w' l=0 窗口"pw"  best=2
r=2 'w' l=2 窗口"w"   best=2
r=3 'k' l=2 窗口"wk"  best=2
r=4 'e' l=2 窗口"wke" best=3
r=5 'w' l=3 窗口"kew" best=3
```

`r=2` 时遇到第二个 `w`，上一个 `w` 在下标 1，`l` 直接跳到 2。

### 容易写错：`l` 只能往右，不能往回退

条件写的是 `last[c] >= l`，不是「`c` 出现过就跳」。区别在于：`c` 上次出现的位置可能已经在窗口左边了，那次出现不算数。

拿 `"abba"` 把两种写法都跑了一遍。只要出现过就跳：

```
r=0 'a' l=0 窗口"a"   best=1
r=1 'b' l=0 窗口"ab"  best=2
r=2 'b' l=2 窗口"b"   best=2
r=3 'a' l=1 窗口"bba" best=3
```

`r=3` 时 `a` 上次出现在下标 0，`l` 被设成 1，从 2 退回了 1。窗口变成 `"bba"`，里面有两个 `b`，答案算成 3，是错的。

加上 `last[c] >= l` 判断之后：

```
r=3 'a' l=2 窗口"ba"  best=2
```

下标 0 的 `a` 已经在窗口外了，不用跳，`l` 留在 2，答案是正确的 2。

这个判断也可以写成 `l = max(l, last[c] + 1);`，意思一样。

时间 $O(n)$，`r` 走一遍，`l` 只跳不挪；空间是固定的 128 个 `int`，算 $O(1)$。

## 三个方案对比

| 方案 | 做法 | 时间 | 额外空间 |
| --- | --- | :---: | :---: |
| 一 | 每个起点往右扩到重复为止 | $O(n^2)$ | $O(1)$ |
| 二 | 滑动窗口，`l` 一格一格收缩 | $O(n)$ | $O(1)$ |
| 三 | 滑动窗口，`l` 一步跳到重复字符后面 | $O(n)$ | $O(1)$ |

三个方案的数组都是 128 个格子，长度固定，和输入多长无关，所以额外空间都算 $O(1)$。

## 这题用到的 C++ 写法

- **`s[r]` 是 `char`，`(int)s[r]` 是它的 ASCII 码**：用字符当数组下标，先转成整数
- **`[]` 有两种意思**：声明时是数组长度，使用时是第几个元素
- **`bool seen[128] = {false}`**：只写第一个元素，其余自动补成同样的初值。但初值要用 `-1` 时就不能这么写，要用循环
- **长度是 `r - l` 还是 `r - l + 1`**：先想清楚 `r` 那一格算不算在内
- **滑动窗口的两个下标都只往右走**：外层套内层 `while` 也是 $O(n)$
